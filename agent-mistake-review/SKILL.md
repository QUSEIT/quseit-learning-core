# 错题复盘

把错题从改正答案升级为找到错误模式并安排复习。

## 解决什么问题

把错题从改正答案升级为找到错误模式并安排复习。学生改完错题就忘、家长只会看分数、老师找不到班级共性问题的根本原因——本技能对此三件事全部有回应。

**本技能完全独立运行**，不需要任何外部工具或教育 runtime，所有分析均在对话中完成。

## 最适合

- 学生日常错题订正（自己用）
- 家长复盘一周错题（辅助孩子）
- 老师整理班级共性问题（批量分析）

## 不适合

- 没有任何错题样本的泛泛复习
- 只想快速抄标准答案的场景
- 需要出套卷、出课件的备课场景（本技能只做复盘，不生成内容）

## 使用前请准备

- 错题题干（原文或照片文字转写）
- 学生原答案
- 正确答案
- 学生当时思路或老师批注（二选一有即可）

**如果不知道如何收集和整理错题**，请先阅读 `references/mistake-collection.md`，里面有引导话术和结构化模板，可以帮助用户快速提供可用信息。

## 推荐工作流

1. **收集错题** — 根据 `references/mistake-collection.md` 引导用户粘贴或口述错题
2. **判断错因** — 根据题干、原答案、批注，判断错误根因类型
3. **给出订正说明** — 用一句话讲清楚正确解法是什么
4. **抽象错误模式** — 从当前批次错题中提炼共性（见下方详细规则）
5. **生成复习动作** — 重做练习 + 同类题 + 间隔复习计划

## 错因分类

错因必须是下拉选项之一，不得用"粗心"泛指：

| 代码 | 名称 | 说明 | 区分一句话 |
|---|---|---|---|
| A | 审题错误 | 看漏条件、理解偏差、用了错误的公式或方法 | 知道用什么公式，但看题时选错了 |
| B | 概念混淆 | 相关但不同的知识点在公式内部混淆 | 不知道用什么公式，或把两个不同公式的结构混在一起 |
| C | 计算错误 | 步骤对但算错了（单独标记）| —
| D | 方法缺失 | 不知道用哪个解题策略 | —
| E | 表达不规范 | 知道做法但写不对格式 | —
| F | 突发失误 | 偶发、非典型，下次注意即可 | — |

**A 与 B 的核心区别：**
- **A（审题错误）**：看到题目后选了错误的公式/方法。比如圆环题用了三角形面积公式，是"看题时判断错了该用哪个公式"。
- **B（概念混淆）**：不知道该用什么公式，或把两个公式的结构混在一起用了。比如分数加减法直接分子加分母，是"公式内部的运算法则没理解"。

**格式示例：**

```json
{
  "错因分类": {
    "代码": "B",
    "名称": "概念混淆",
    "说明": "把'体积'和'容积'混用了，导致单位换算全部反向"
  }
}
```

## 正确解法

**格式示例：**

```json
{
  "正确解法": {
    "简要步骤": ["分清体积与容积的定义", "确认单位统一为L", "代入公式V=πr²h计算"],
    "关键点": "体积从外部测，容积从内部测，单位换算率不同",
    "注意事项": ["别把cm³当成mL换算", "圆形底面积要先算πr²"]
  }
}
```

## 抽象错误模式

这是本技能的核心认知步骤，必须严格按以下三条规则执行：

**规则一：同知识点错误 → 合并**
3道以上错题指向同一知识点（如"分数加减法"），标记为"知识点系统性薄弱"，后续复习优先覆盖。

**规则二：同类型思路错误 → 归纳**
多道错题用了相同的错误思路（如"遇到应用题就套公式、不分析数量关系"），提炼为"思路模式错误"，生成针对性思维训练。

**规则三：突发性错误 → 单独处理**
某道错题与其他题目无共性，是偶发失误（审题跳行、计算手滑），归入 F 类，不纳入复习计划主干，只需当天重做一次即可。

**格式示例：**

```json
{
  "错误模式": {
    "类型": "知识点系统性薄弱",
    "涉及知识点": ["分数加减法通分", "分数加减法约分"],
    "覆盖错题数": 4,
    "建议": "先补通分概念，再做3道练习，确认后再推进到约分"
  }
}
```

## 复习计划

按艾宾浩斯遗忘曲线简化版给出节奏：

| 轮次 | 时间点 | 动作 |
|---|---|---|
| 第0轮 | 当天 | 订正原题，写出完整解题过程 |
| 第1轮 | 次日 | 重做原题（不看答案，计时） |
| 第2轮 | 第3天 | 做1道同类题，检验迁移能力 |
| 第3轮 | 第7天 | 做2道同类题，任意题型混合 |
| 第4轮 | 第30天 | 做3道综合题，模拟测试形式 |

**停止条件**：某轮正确率连续两次达到 100%，该知识点从复习队列中移除，标记为"已掌握"。

**格式示例：**

```json
{
  "复习计划": {
    "知识点": "分数加减法通分",
    "当前状态": "复习中",
    "计划": [
      {"轮次": 0, "时间": "今天", "动作": "订正原题，写完整过程"},
      {"轮次": 1, "时间": "明天", "动作": "重做原题，不看答案"},
      {"轮次": 2, "时间": "第3天", "动作": "做1道同类题"},
      {"轮次": 3, "时间": "第7天", "动作": "做2道混合同类题"},
      {"轮次": 4, "时间": "第30天", "动作": "3道综合题模拟测试"}
    ],
    "停止条件": "连续两次100%正确"
  }
}
```

## 质量检查

- 错因必须基于题目和原答案推导，禁止凭空判断
- 错因代码 F（突发失误）不得超过总题数的 30%，否则重新审视是否有隐藏共性
- 复习动作必须可执行（有时间点、有具体行为），禁止输出"注意复习"类废话
- 错误模式提炼必须有至少 2 道题佐证，不允许单题归纳

## 调用信号

用户可能用以下方式触发本技能：

- 明确意图：错题订正、错题复盘、单元复习、帮我分析错题
- 模糊意图：考试没考好、最近学习有问题、需要复习计划
- 老师场景：班级共性问题、错题整理、复习建议

## 适用角色

- **学生**：自己用手机拍照上传错题，获得分析 + 复习计划
- **家长**：把孩子本周错题发过来，获得家庭复习建议
- **老师**：把班级错题数据发过来，获得重点知识点排序
