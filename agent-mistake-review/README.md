# agent-mistake-review

把错题从改正答案升级为找到错误模式并安排复习。

## 简介

这是一个面向学生、家长和老师的错题复盘技能。不只是告诉孩子"正确答案是什么"，而是：

1. **找错因** — 判断是审题错误、概念混淆、计算错误、方法缺失、表达不规范还是突发失误
2. **订正说明** — 用一句话讲清楚正确解法
3. **提炼模式** — 从多道错题中找出共性错误模式
4. **安排复习** — 按艾宾浩斯遗忘曲线给出 5 轮复习计划

## 安装

本技能已在 `learning-core/` 分类下本地部署，通过 Hermes 自动加载，无需额外配置。

## 使用方法

### 触发方式

直接用自然语言描述错题，不需要特定指令格式：

```
帮我分析这道错题
孩子这次考试错了3道题
开始错题复盘
```

### 提供错题

把错题发给我，格式随意，以下任选其一：

**方式 A：直接粘贴**
```
题目：2/3 + 1/4 = ？
孩子答案：3/7
正确答案：11/12
```

**方式 B：多道题**
```
【错题1】
题目：___
孩子答案：___
正确答案：___

【错题2】
题目：___
孩子答案：___
正确答案：___
```

发 3 道以上效果最好，1 道也可以分析。

### 输出内容

我会输出完整的**错题复盘卡片**，包含：

- 每道题的错因分类（A～F）
- 正确解法与关键步骤
- 一句话订正
- 错误模式提炼（多题时）
- 复习计划（当天 → 次日 → 第3天 → 第7天 → 第30天）

## 错因分类

| 代码 | 名称 | 说明 |
|---|---|---|
| A | 审题错误 | 看漏条件、理解偏差、用了错误的公式或方法 |
| B | 概念混淆 | 相关但不同的知识点在公式内部混淆 |
| C | 计算错误 | 步骤对但算错了 |
| D | 方法缺失 | 不知道用哪个解题策略 |
| E | 表达不规范 | 知道做法但写不对格式 |
| F | 突发失误 | 偶发失误，下次注意即可 |

## 适用角色

| 角色 | 能做什么 |
|---|---|
| 学生 | 自己用手机拍照上传错题，获得分析 + 复习计划 |
| 家长 | 把孩子本周错题发过来，获得家庭辅导建议 |
| 老师 | 把班级错题数据发过来，获得重点知识点排序 |

## 独立运行

本技能完全独立，不需要任何外部工具或教育 runtime，所有分析均在对话中完成。
