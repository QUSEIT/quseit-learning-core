# agent-mistake-review 测试集

## 测试说明

每个测试项包含：
- **输入**：用户输入的提示词
- **预期**：Agent 应输出的关键要素（不必完全字面匹配，但必须包含）
- **覆盖点**：测试的核心能力

---

## 基础能力测试

### T1：审题错误识别（A类）

**输入：**
> 孩子这次数学考了87分，最后一题求圆环面积，孩子写的答案是0.5×3.14×(5²-3²)=0.5×3.14×16=25.12，正确答案是25.12，帮我分析一下错因。

**预期输出要素：**
- [ ] 错因代码为 A 或 审题错误
- [ ] 指出公式错误：圆环面积公式是 π(R²-r²) 不是 0.5×π×(R²-r²)
- [ ] 一句话订正
- [ ] 复习计划（当天/次日/第3天）

---

### T2：概念混淆识别（B类）

**输入：**
> 帮我分析这道题：题目是"一个水池长5米、宽3米、深2米，这个水池能装多少升水？"孩子写的答案是5×3×2=30（立方米）=30000升，正确答案也是30立方米=30000升。

**预期输出要素：**
- [ ] 错因代码为 B 或 概念混淆（注意：本题答案对，但可深入追问孩子对体积与容积的真正理解）
- [ ] 分析角度：孩子对"立方米"与"升"的换算是否真正理解
- [ ] 订正说明：体积单位换算的标准步骤
- [ ] 复习计划

---

### T3：计算错误识别（C类）

**输入：**
> 题目：25×4=？孩子答案：82，正确答案：100。帮我分析。

**预期输出要素：**
- [ ] 错因代码为 C 或 计算错误
- [ ] 指出计算过程错误（25×4=82 错在哪里：进位问题）
- [ ] 正确乘法步骤
- [ ] 复习计划（计算类需要额外练习）

---

### T4：方法缺失识别（D类）

**输入：**
> 孩子遇到应用题就发呆，这道题："小明有12颗糖，给了小红3颗，又得到了5颗，现在有几颗？"孩子答案是12颗，说"不知道为什么要算"。帮我分析。

**预期输出要素：**
- [ ] 错因代码为 D 或 方法缺失
- [ ] 分析：孩子不理解两步运算的应用题结构
- [ ] 教授思路：先找"给了"是减少，"得到"是增加
- [ ] 复习计划：D类需要专项思维训练，不是多做题能解决的

---

### T5：表达不规范识别（E类）

**输入：**
> 几何证明题：证明三角形内角和是180度。孩子答案写的是"因为三角板有三个角，所以加起来是180度"。正确答案需要写出"延长BC至D，设∠C=∠ACD，在同位角相等的条件下∠A+∠B+∠C=180°"。帮我分析。

**预期输出要素：**
- [ ] 错因代码为 E 或 表达不规范
- [ ] 指出证明缺少逻辑推理过程
- [ ] 给出规范的证明步骤格式
- [ ] 复习计划

---

### T6：突发失误识别（F类）

**输入：**
> 孩子计算0.75+0.25，答案是0.90，我检查了一下他说"我知道了！应该是1！"这次帮他分析一下。

**预期输出要素：**
- [ ] 错因代码为 F 或 突发失误
- [ ] 订正：0.75+0.25=1.00，小数点对齐后第三位进位
- [ ] F类归入当天重做，不进主干复习计划
- [ ] 质量检查提示：F类是否超过总数30%

---

## 多题与模式提炼测试

### T7：三道同类题，提炼知识点系统性薄弱

**输入：**
> 孩子最近三道数学题都错了，都是分数问题：
>
> 题1：2/3+1/4=？孩子答案：3/7
> 题2：5/6-1/3=？孩子答案：4/3
> 题3：1/2+1/4=？孩子答案：2/6
>
> 帮我找共性错误。

**预期输出要素：**
- [ ] 识别三道题都是通分错误
- [ ] 错误模式类型：知识点系统性薄弱
- [ ] 涉及知识点：分数加减法通分
- [ ] 复习计划优先覆盖通分

---

### T8：多道含混合错误，提炼思路模式错误

**输入：**
> 孩子这次作业错了5道：
>
> 题1：应用题"买3支笔每支2.5元，付10元找回？"孩子答：10-3×2.5=2.5（正确）
> 题2：应用题"妈妈买2千克苹果，每千克6.5元，付20元找回？"孩子答：20-2×6.5=7（正确）
> 题3：应用题"一根绳子长5.8米，用去1.9米，还剩？"孩子答：5.8-1.9=4.9（正确）
> 题4：应用题"小明有20元，买4本笔记本每本3.5元，还剩？"孩子答：20-4×3.5=6（元），但单位写成了"米"
> 题5：应用题"爸爸买3.5千克排骨，每千克45元，共花？"孩子写对了算式3.5×45=157.5，但最终答案写了157元

**预期输出要素：**
- [ ] 识别第4题是E类（表达不规范：单位写错）
- [ ] 识别第5题是C类（计算错误：最后一步四舍五入失误）
- [ ] 提炼错误模式：不是知识点问题，而是解题后不检查答案合理性
- [ ] 建议：增加"答后验算"思维习惯

---

### T9：突发失误和系统薄弱同时出现

**输入：**
> 孩子这次数学错了6道，帮我全面分析：
>
> 题1：24÷3=？答案：8（正确）
> 题2：72÷8=？答案：7（错误，应该9）
> 题3：56÷7=？答案：6（错误，应该8）
> 题4：48÷6=？答案：9（错误，应该8）
> 题5：判断题"小明身高14米"（×）
> 题6：判断题"小学生一节课40分钟"（√）

**预期输出要素：**
- [ ] 题2/3/4 → B类（乘法口诀不熟，除法本质是乘法的逆运算没建立）
- [ ] 题5 → A类（审题错误，14米不符合实际生活常识）
- [ ] 题6 → F类（偶发失误，对时长感知准确）
- [ ] F类占比：1/6 ≈ 16.7% < 30%，通过质量检查
- [ ] 错误模式：除法运算系统薄弱

---

## 角色与场景测试

### T10：家长辅助角色

**输入：**
> 我是孩子的妈妈，孩子三年级，这次数学考了78分，错题信息如下：
>
> 题1：300+50=？孩子答案：800
> 题2：120-30=？孩子答案：30（正确是90）
> 题3：450+80=？孩子答案：530（正确）
> 题4：200-70=？孩子答案：170（正确是130）

**预期输出要素：**
- [ ] 从家长角度输出，语气温和实用
- [ ] 不需要解释复杂的教学理论
- [ ] 给出具体可操作的家庭辅导建议
- [ ] 复习计划要家长能在家执行

---

### T11：老师批量分析角色

**输入：**
> 我是小学数学老师，这次单元测试全班42人，整理了出错率最高的三道题：
>
> 第1题（52÷8=？）：有18人答错，其中12人写7，6人写6
> 第2题（判断：0不是自然数）：有15人答错，都选了√
> 第3题（应用：小明有20颗糖，平均分给4人，每人几颗？）：有11人答错，主要是计算错误

**预期输出要素：**
- [ ] 识别三类不同错因
- [ ] 给出班级整体复习建议
- [ ] 优先级排序（52÷8 出错率最高优先）
- [ ] 不需要个性化复习计划，需要班级共性方案

---

### T12：单元复习场景（参数化）

**输入：**
> 孩子六年级，下周期末考试，数学第五单元是圆，要怎么复习这单元的错题？
>
> 题1：圆的周长公式用 C=πd 还是 C=2πr？
> 题2：圆环面积公式是什么？
> 题3：一个圆半径是3cm，直径是？
> 题4：已知圆半径是4cm，求周长（π取3.14）
> 题5：已知圆的周长是12.56cm，求半径（π取3.14）

**预期输出要素：**
- [ ] 覆盖六年级圆的知识点：周长公式、面积公式、圆环、圆心、半径、直径
- [ ] 每道题给出 A/B/C/D/E 错因分类
- [ ] 生成单元复习计划，含优先级
- [ ] 区分哪些是概念题，哪些是计算题

---

## 边界与异常测试

### T13：只发一道题

**输入：**
> 帮我分析这道题：2/3+1/2=？孩子答案：2/5。

**预期输出要素：**
- [ ] 正常分析，不报错
- [ ] 明确告知用户"只有一道题无法提炼错误模式，建议发3道以上"
- [ ] 仍输出完整复盘卡片

---

### T14：缺少正确答案

**输入：**
> 孩子写了"一个数的平方是16，这个数是多少？"答案是4，老师打了叉。正确答案是什么我不知道。

**预期输出要素：**
- [ ] 不因缺少正确答案而卡住
- [ ] 主动分析两种可能性：孩子填4还是-4
- [ ] 给出知识说明：±4 的情况
- [ ] 标注"正确答案待确认"

---

### T15：全是突发失误（F类>30%）

**输入：**
> 孩子这次错了3道：1. 计算2+3=5写成了2+3=6；2. 应用题单位写错了；3. 判断题审题没看清楚"不正确"三个字。

**预期输出要素：**
- [ ] 三道都是F类，占比100%
- [ ] 质量检查触发警告：F类已超30%，请重新审视是否有隐藏共性
- [ ] 尝试深层分析：看似无关但可能反映同一问题（做题急躁、不检查）
- [ ] 提炼出"解题后不检查"作为真实错误模式

---

### T16：无文字只有描述

**输入：**
> 帮我看看这道题，孩子写的答案在图里，我看不懂他写的啥，只知道这道题老师打了叉。

**预期输出要素：**
- [ ] 不因没有文字而拒绝
- [ ] 说明需要用户提供文字版题目和孩子答案
- [ ] 给出引导话术，让用户知道怎么描述

---

### T17：错题顺序混乱

**输入：**
> 孩子错了5道题（题3：没看清题目要求；题1：算错了；题5：概念混淆；题2：方法不会；题4：表达不规范）。帮我分析。

**预期输出要素：**
- [ ] 不因顺序混乱而失败
- [ ] 能正确识别每道题并按错因分类
- [ ] 输出时重新整理，按错因类型分组

---

### T18：用户说"就是粗心"

**输入：**
> 孩子这次数学错了2道，我看了就是粗心，没什么好分析的，帮我安排复习计划就行。

**预期输出要素：**
- [ ] 不接受"粗心"作为错因
- [ ] 主动追问：到底是哪一步错了？审题？计算？抄写？
- [ ] 用质量检查规则引导用户区分具体类型
- [ ] 不能因为用户说"粗心"就跳过分析步骤

---

### T19：复习动作必须是可执行的

**输入：**
> 帮我分析这道题，然后安排复习：
> 题目：x²-5x+6=0，求x。孩子答案：x=1（正确答案：x=2或x=3）。

**预期输出要素：**
- [ ] 错因分析：孩子因式分解未掌握（x²-5x+6=(x-2)(x-3)=0）
- [ ] 复习计划中的动作必须是具体的（时间+行为），禁止"注意复习"
- [ ] 停止条件明确（连续两次100%正确）
- [ ] 给出因式分解专项练习建议

---

## 运行方式

在 Hermes 对话中逐条输入测试，观察输出是否符合"预期输出要素"中的所有检查项。

建议顺序：
1. 先跑 T1～T6（基础能力，确保六类错因都能正确识别）
2. 再跑 T7～T9（模式提炼，确保多题场景不失效）
3. 再跑 T10～T12（角色场景，确保输出有针对性）
4. 最后跑 T13～T19（边界异常，确保降级和异常处理到位）

全部通过后，技能可认为达到 production-ready。
