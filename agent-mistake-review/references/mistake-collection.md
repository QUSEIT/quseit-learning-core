# 错题收集模板与 Agent 引导话术

本文档替代 `mistake.query_recent` 工具，让 Agent 在没有任何外部错题库的情况下，也能引导用户高效提供错题数据。

---

## 一、用户粘贴格式（最低要求）

请用户按以下格式粘贴错题，每道至少包含题干 + 学生原答案：

```
题目：[这里写题目全文]
学生原答案：[孩子当时写的答案]
正确答案：[标准答案]
（可选）当时思路或老师批注：[口述或文字描述]
```

如果用户不知道正确答案，Agent 应主动帮查或标注"待确认"。

---

## 二、Agent 引导话术模板

### 场景 A：用户说"帮我分析错题"但没发题目

> 请把孩子的错题发给我，格式不限，但最好包含以下信息：
> 1. 题目是什么（拍照发图也可以，我来看）
> 2. 孩子当时写的答案是什么
> 3. 正确答案是什么（如果知道的话）
> 
> 发 3 道以上效果最好，这样我能找出共性问题。

### 场景 B：用户发了一堆文字但没有结构

> 收到，我看到这些内容了。帮我确认一下孩子的答案和正确答案，方便我做分析吗？格式可以是：
> - 题目：xxx
> - 孩子答案：xxx  
> - 正确答案：xxx
> 
> 发一道也可以分析，但三道以上我能找到规律。

### 场景 C：有多题但不确定哪些重要

> 先把这一周的错题都发过来，我来判断哪些有共性、哪些是偶发失误。不需要特意筛选，全发过来就行。

---

## 三、快速收集三步法（Agent 内部逻辑）

当用户触发错题复盘但提供的信息不完整时，Agent 按以下步骤索取信息：

**第一步：确认题目**
- 如果用户只说"数学考砸了"，问：能发一道具体的错题过来吗？
- 如果用户发了图片，主动说：请把题目文字也发我，我好做分析。

**第二步：确认原答案和正确答案**
- 如果用户只发了题目和正确答案，问：孩子当时写的答案是什么？

**第三步：确认思路或批注（可选）**
- 如果有余力，问：孩子当时是怎么想的？或者老师有没有写批注？

三步完成即进入复盘流程，不必等全部信息完整才能开始。

---

## 四、批量收集提示词（多题场景）

如果用户要一次性分析 5 道以上错题，用以下结构化提示让用户填写：

```
请按以下格式填写，复制粘贴即可，不需要打字：

【错题1】
题目：___
学生原答案：___
正确答案：___
老师批注/学生思路（可选）：___

【错题2】
题目：___
学生原答案：___
正确答案：___
老师批注/学生思路（可选）：___

……（继续添加）
```

Agent 收到后，先整理、再分析，不需要用户自己分类。
