# AI 讲题 Skill

把一道题讲到学生**真正会复述思路**：先定位卡点，再用年级能听懂的语言拆解，最后用变式题确认理解。

## 功能特性

- ✅ **先定位卡点** — 找出学生具体卡在哪一步
- ✅ **年级适配讲解** — 用该年级能听懂的语言讲解关键思路  
- ✅ **变式题确认** — 用同类题目检验学生是否真正掌握（举一反三）
- ✅ **质量保证** — 不直接给答案，每步说明依据

## 适用场景

- 课后作业辅导
- 课堂知识同步巩固
- 薄弱知识点专项突破

## 适用人群

- 🎓 **学生** — 作业卡住但不想直接抄答案
- 👨‍👩‍👧 **家长** — 需要把题讲清楚
- 👨‍🏫 **老师** — 想生成分层讲解和追问题

## 快速开始

### 1. 加载技能

```
load skill agent-question-explanation
```

### 2. 提问方式

告诉技能：

- **题目**（文字或图片）
- **年级**（如六年级、高一）
- （可选）希望讲到什么深度

### 示例

```
你：这道题我不会
    题目：2x + 5 = 13
    年级：七年级
```

技能会：
1. 确认题意
2. 询问你卡在哪一步
3. 用七年级能听懂的语言讲解
4. 给出分步过程和易错提醒
5. 给一道同类变式题检验你是否真正掌握

## 不适合的场景

- ❌ 考试实时作弊
- ❌ 只要求最终答案且拒绝过程解释
- ❌ 题干缺失关键条件且无法补充
