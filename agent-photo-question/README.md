# agent-photo-question

**拍照题目的 AI 讲题教练** — 把"给答案"变成"教思考"

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Hermes Skill](https://img.shields.io/badge/Skill-Hermes-blue.svg)]
[![Version](https://img.shields.io/badge/Version-0.11.0-green.svg)](SKILL.md)

## 🎯 核心功能

学生拍照上传题目，AI 按**建构主义理念**分步讲解：
1. **识别题干** → 确认模糊内容
2. **拆解条件-目标-方法-步骤** → 讲思路
3. **追问确认** → 检查理解
4. **易错提醒** → 避免陷阱
5. **变式检验** → 同类题练习

## 📚 适用场景

| ✅ 适合 | ❌ 不适合 |
|--------|----------|
| 自学学生 | 纯答案需求 |

## 🚀 快速开始

### 最简单的使用

```
开始拍照答疑
```
然后**发一张题目图片**，AI 就会开始讲解流程。

### 更多触发方式

```
帮我做拍照答疑
拍照答疑 Skill
根据当前上下文执行拍照答疑 Skill
```

### 指定年级讲解

```
我把数学题文字贴给你，请按五年级水平讲解。
这道物理题我卡在受力分析，帮我拆条件。
帮我看这道题，我完全不知道从哪下手。
```

## 🔄 工作流

```
用户发图
  ↓
vision_analyze 识别题干
  ↓
[置信度 < 0.7？] → 是 → 标注不确定内容，请用户确认后继续
  ↓
按年级讲解深度（见下方分级参考）讲解
  ↓
追问确认（见追问协议）
  ↓
给出同类变式题（需满足质量约束）
  ↓
变式题附完整解答，供用户自行核对
```

## 📊 参数化使用

这个 Skill 不再把年级、册别、单元、知识点和难度拆成大量独立 Skill。请在调用时通过参数或自然语言补充这些信息。

- **Grades**: `一年级`~`高三`（共12个年级）
- **Semesters**: `上册`, `下册`, `必修一`, `必修二`, `选择性必修`
- **Scenarios**: `拍照答疑`, `课后作业`
- **Difficulties**: `基础`, `标准`, `提高`
- **Parameterized Dimensions**: `grade`, `semester`, `unit`, `lesson`, `knowledgePointCodes`, `scenario`, `difficulty`

## 🎨 特色设计

### 教育理念
- **建构主义**：不是直接给答案，而是引导学生自己思考
- **确认交互**：先确认模糊内容，再讲解
- **易错提醒**：针对常见陷阱预警
- **变式闭环**：出同类题检验理解程度

### 质量保障
- **变式题四条约束**：同知识点、可验证、难度±1级、提供答案
- **年级分级讲解**：小学1-3/小学4-6/初中/高中四档深度
- **追问协议**：回答错误时引导重试，3次失败后提示求助

### 技术特色
- **视觉识别集成**：内置 `vision_analyze` 直接处理图片
- **结构化输出**：JSON 格式输出，便于解析和验证
- **工具链轻量**：仅依赖 Hermes 内置能力，无需额外安装
