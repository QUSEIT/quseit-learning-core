# Agent Memory Method Skill

## 概述

本技能将需要记忆的内容转化为可提取、可复述、可间隔复习的记忆任务，而不是反复机械朗读。

## 核心特性

- **记忆任务化**: 将知识转化为具体的记忆任务
- **间隔复习**: 基于艾宾浩斯遗忘曲线设计复习计划
- **可提取性**: 确保记忆内容可以被主动提取
- **可复述性**: 支持用自己的话复述知识点

## 使用场景

- 记忆单词、术语
- 复习考试知识点
- 巩固学习内容
- 长期知识积累
