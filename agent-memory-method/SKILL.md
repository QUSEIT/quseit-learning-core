# 记忆方法 Skill

把需要背的内容变成可提取、可复述、可间隔复习的记忆任务，而不是反复机械朗读。

## 解决什么问题 / Problem

将学习者讨厌的"机械重复朗读"转变为有策略的记忆训练：
- **主动提取** > 反复朗读（提取练习效应）
- **间隔复习** > 集中背诵（遗忘曲线）
- **理解优先** > 死记硬背（先懂再背）

## 最适合 / Best For

- 古诗词/文言文背诵
- 英语单词/词组
- 公式/定理/概念定义
- 历史年表/地理要素

## 不适合 / Not For

- 单次量 > 500 字的内容（建议分批）
- 完全不理解的内容强行长期记忆（先理解再背诵）
- 非文字类（图片/音频/动作技能）

## 使用前请准备 / Inputs

| 字段 | 必填 | 说明 |
|---|---|---|
| 要记忆的文本 | ✅ | 直接粘贴文字内容 |
| 年级 | ✅ | 如"三年级"、"高一" |
| 截止时间 | ❌ | 如"下周考试" |
| 已掌握程度 | ❌ | 如"能背一半，三四句容易忘" |
| 容易忘的部分 | ❌ | 如"《静夜思》第三句总是想不起来" |

> 字段可以通过自然语言一次性提供，不需要结构化输入。

---

## 推荐工作流 / Workflow（5步）

**第1步：切分记忆块**
- 诗歌/文言文：按**句**或**联**切分，每块 ≤ 20字
- 单词：按**主题/词根/词性**分组，每组 5-10 个
- 公式/概念：每条公式/定义独立成块
- 总字数 < 200字：一次性处理；200-500字：分成 2-3 批；> 500字：建议用户分批

**第2步：设计提取线索**
每个记忆块对应 1 个**填空题**和 1 个**开放问答题**，示例：
- 填空：`床前明月光，_______。`（答案：疑是地上霜）
- 问答：`这句诗描写的是什么时节？用自己的话说。`

**第3步：安排首次背诵**
- 步骤：① 读 3 遍 → ② 遮住内容背 1 遍 → ③ 对照原文纠正 → ④ 再背 1 遍
- 目标：能**闭眼完整复述**，不看原文

**第4步：生成间隔复习表**
使用以下 5 个节点（第1天起算），在表格中填入具体日期：

| 次数 | 距首次 | 形式 |
|---|---|---|
| 第1次 | 第1天（当天） | 闭眼背诵全文 |
| 第2次 | 第3天 | 填空题练习 |
| 第3次 | 第7天 | 问答复述 |
| 第4次 | 第14天 | 闭眼背诵全文 |
| 第5次 | 第30天 | 综合测试（全部题型） |

**第5步：自测检验**
- 给出 3 道题（1 填空 + 1 问答 + 1 判断对错）
- 每道题标出**考察的记忆块编号**，便于定位弱点

---

## 输出格式 / Output Format

每个完整输出的结构如下：

| 部分 | 说明 |
|---|---|
| 记忆块切分 | 表格：编号 + 内容 + 记忆提示 |
| 提取问题 | 每个记忆块对应 1 个填空题 + 1 个开放问答题 |
| 首次背诵步骤 | 读 3 遍 → 遮住背 → 对照纠正 → 再背 |
| 间隔复习表 | Markdown 表格：次数 + 日期 + 复习形式 |
| 自测题 | 3 道题（1 填空 + 1 问答 + 1 判断），标出考察的记忆块编号 |

---

## 成功标准 / Quality Checks（输出必须全部满足）

1. **主动回忆**：输出中必须有提取问题（填空/问答），而非仅列出要背的内容
2. **复习节点明确**：表格必须包含 ≥ 4 个日期（距首次 ≥ 1天、3天、7天、14天）
3. **步骤可操作**：每个记忆块都有"读×遍→遮住背→纠正→再背"的步骤说明
4. **区分理解和记忆**：输出中明确说明哪些地方需要先理解（释义），哪些是纯记忆
5. **总量约束**：单次输出记忆块数量 ≤ 10 个；超过时提示用户分批

## 示例 / Examples

### 示例1：古诗词

**输入（用户）**
> 帮我背《静夜思》，三年级，下周考试。第二句和第三句容易忘。

**输出（技能生成）**

```
## 记忆块切分

| 编号 | 内容 | 记忆提示 |
|---|---|---|
| B1 | 床前明月光 | "床前"即床边，画面感记忆 |
| B2 | 疑是地上霜 | "疑"=好像，地上霜=秋夜露水 |
| B3 | 举头望明月 | 抬头看，动作+对象 |
| B4 | 低头思故乡 | 低头想家，对应"举头" |

## 提取问题

- 填空：`举头望_______，低头思故乡。`
- 问答：`"明月光"指的是什么？用自己的话说。`

## 首次背诵步骤

1. 朗读全诗 3 遍（注意停顿：床前/明月光，疑是/地上霜……）
2. 遮住内容，背诵 1 遍
3. 打开对照，标记错漏处（重点看 B2、B3）
4. 再完整背 1 遍

## 间隔复习表

| 次数 | 日期 | 形式 |
|---|---|---|
| 第1次 | 10月20日（今天） | 闭眼背诵全文 |
| 第2次 | 10月23日 | 填空题练习 |
| 第3次 | 10月27日 | 问答复述 |
| 第4次 | 11月3日 | 闭眼背诵全文 |
| 第5次 | 11月20日 | 综合测试 |

## 自测题

1.【B2 填空】疑是_______。
2.【B3 问答】诗人为什么要"举头望明月"？说说你的理解。
3.【综合判断】《静夜思》描写的是夏天夜景。（×）
```

### 示例2：英语单词

**输入（用户）**
> 高一学生，帮我记这5个单词：abandon, ability, abnormal, aboard, absolute。容易和词形相近的词混淆。

**输出（技能生成）**

```
## 记忆块分组（词根词缀法）

| 编号 | 单词 | 词根/记忆法 | 中文 |
|---|---|---|---|
| W1 | abandon | ab-离开 + bandon→绑，解除束缚 | 放弃 |
| W2 | ability | abil(能)+ity（名词后缀） | 能力 |
| W3 | abnormal | ab-偏离 + normal（正常） | 异常的 |
| W4 | aboard | a-在…上 + board（船板）→上船 | 在船/飞机上 |
| W5 | absolute | ab-离开 + solute（溶解）→完全松开 | 绝对的 |

## 提取问题（5选3）

- 填空：She had the _______ to finish the marathon.（答案：ability）
- 问答：abnormal 和 normal 是什么关系？词根 ab-在这里表示什么意思？
- 判断：absolutely 是 absolute 的副词形式。（√）

## 首次背诵步骤

1. 看单词，大声读 3 遍，读准发音
2. 遮住中文，说出意思；遮住单词，说出拼写（双向练习）
3. 混淆单词（abandon vs abnormal）对比背 1 遍
4. 默写 5 个单词，对照检查

## 间隔复习表

| 次数 | 日期 | 形式 |
|---|---|---|
| 第1次 | 今天 | 双向默写 |
| 第2次 | 第3天 | 填空+问答 |
| 第3次 | 第7天 | 混淆词对比练习 |
| 第4次 | 第14天 | 综合测试 |
| 第5次 | 第30天 | 回顾全部 |

## 自测题

1.【W1 填空】他______了戒烟的尝试。（答案：abandoned）
2.【W3 问答】abnormal 的反义词是什么？词根 ab-在这里的含义？
3.【综合判断】aboard 可以指在船上，也可以在飞机上。（√）
```
